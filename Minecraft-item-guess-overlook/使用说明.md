# Minecraft 物品筛选表

双击本文件夹中的 `index.html` 即可打开。197 条物品数据已内嵌在 HTML 中，离线也可使用，无需安装或启动服务。

- 名称列：输入物品名称的一部分进行模糊搜索，忽略大小写、全角与半角差异。多个空格分开的词需要同时出现在名称中。
- 九类标签：点击对应表头，勾选该列的标签，立即更新结果。每一列的选择相互独立。
- 同列默认“满足任一”；切换“全部满足”可要求物品包含所选全部标签。不同列之间始终需要同时满足。
- 下拉框中的数字表示在其他列和名称条件下含此标签的物品数量，所有标签均保留供选择。
- “清除此列”只清空当前列；“清空筛选”恢复全部 197 个物品。顶部条件条上的 × 可移除对应条件。
- “导出结果”保存当前筛选结果为 CSV，包含名称和九类原始标签。
- 表头与名称列固定；较小屏幕可横向滚动查看全部列。

数据来自已核对的幽幽子机器人原始表格，采集日期为 2026-10-15。页面保留机器人标签原文，不根据正文增补标签。空项以原表的“无”标签保留；比较箭头不进入数据。原始记录及来源证据保存在 `qq-minecraft-collector/data`。

主文件夹的 `index.html` 已加入“Minecraft 物品筛选表”入口。
