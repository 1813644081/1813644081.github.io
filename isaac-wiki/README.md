# 以撒 Wiki 本地 HTML 镜像

此目录包含已保存的原站首页、本地 HTML 阅读服务，以及通过用户 Chrome 正常访问原站的全站导出扩展。**准备下载工具不代表全站已经下载完成**，以本地进度页的实际状态为准。

## Windows 可执行版（无需外部浏览器）

双击 `IsaacWikiDownloader.exe`，即可在程序内连接原站、下载、暂停续传和阅读离线 Wiki。无需启动 Chrome 或安装扩展，Node 已随目录打包；本机已有微软 WebView2 Runtime。程序启动后先在“原站验证”标签页正常完成原站要求的验证，再点击“开始 / 继续下载”。资源域名也可能要求在程序内验证。

加速版默认以 2 路并发下载页面，每路完成后等待 200 毫秒；可在开始前选择稳妥模式（1 路 / 350 毫秒）或更快模式（4 路 / 150 毫秒）。页面处理完毕后单路下载素材。暂停并等待当前任务结束后可切换速度；显示本轮平均完成项数，实际速度取决于原站响应。任务领取与进度统计使用索引，进度日志仅写入变化，关闭程序时合并保存。已有下载文件和进度可以继续使用。

请保留整个 `isaac-wiki` 文件夹，EXE 依赖配套 DLL、`runtime`、`desktop` 和主目录文件。详细说明见 [`desktop/使用说明.md`](desktop/使用说明.md)。程序使用独立网页引擎配置目录，不读取或复制 Chrome 的 Cookie、密码或浏览资料。

组件检查和启动初始化已验证；原站批量下载仍取决于原站的正常访问及验证结果，制作 EXE 不代表绕过了 Cloudflare 或已经完成全站镜像。

## 使用

1. 双击 `start.cmd`，打开 <http://127.0.0.1:8765/>。本机已安装 Node.js，无需 npm 依赖。关闭终端会停止本地服务；下次双击可重新启动。
2. 在 Chrome 扩展管理页开启开发者模式，点击“加载已解压的扩展程序”，选择 `D:\程序\personal blog\isaac-wiki\extension`。
3. 回到已能访问的 `https://isaac.huijiwiki.com/` 标签页，点击“以撒 Wiki 本地导出助手”扩展按钮。先“检查连接”，成功后“开始 / 继续”。
4. 下载期间保持该标签页和本地服务运行。下载速度限制为每次完成请求后至少等待 800 毫秒，逐个下载；所需时间和磁盘空间取决于原站当前规模，不预先声称固定数值。
5. 全站完成后，停止导出或移除扩展，仍可通过 `start.cmd` 完全断网浏览 `site` 内已下载的内容。

## 范围与保真

- 通过 MediaWiki `siteinfo` + `allpages` 按所有非负命名空间枚举当前公开页面。包含条目、分类、文件介绍、模板、帮助等，并保留重定向。
- 通过 `allimages` 枚举全部当前上传的原始文件；下载页面引用的图片、响应式图片、样式、CSS 导入、字体及精灵图。
- HTML 中的站内文章链接指向本地 `/wiki/` 路由。本地搜索按已下载标题匹配。原站或其他网站链接明确需要联网。
- 保存原站正文，保留来源与版权入口。账号、编辑器和个人导航不会写入离线 HTML；扩展不读取、导出或记录 Cookie、密码与账号令牌。
- 静态版不提供原站登录、编辑、历史修订、动态特殊页面、复杂 JavaScript 动画播放器。常见折叠与标签面板会静态展开。它不是原站服务器功能的完整克隆。
- 只有目录枚举完成，且队列、失败和未支持资源均为零，才报告“全站静态下载完成”。失败或遗漏会明确报告，不以首页完成代替全站完成。

## 断点续传与错误

- 使用进度页“暂停下载”或扩展面板“暂停”。之后在 Wiki 标签页的扩展面板点击“开始 / 继续”。
- 403、401、429、API maxlag 或验证页会停止请求。用户在原站正常完成验证后继续；工具不会自动解验证。
- 普通资源错误最多尝试三次。进度页可以查看失败清单，点击“重新排队失败任务”后，再在扩展中继续。
- 其他 CDN 域名或大于 64 MB 的单个素材会列为未完成项目，需要检查后补充支持，不能静默当作成功。
- 状态快照与增量进度：`data/state.json`、`data/progress.jsonl`；离线页面：`site/pages/`；素材：`site/assets/`；失败日志：`logs/errors.jsonl`。增量保存避免每张图片都重写全站目录。

## 本地访问与权限

本地服务仅监听 `127.0.0.1:8765`，不开放到局域网。写入接口使用自动生成的本机配对密钥，拒绝其他网页来源，限制写入固定站点目录。离线页面的内容安全策略只允许本地资源。素材只通过明列的原站 CDN 请求；所有导出数据保存在本机，不上传到第三方服务。

扩展权限为 `activeTab`、`scripting`、本机服务以及原站四个素材域名。只有在用户点击扩展后才读取当前 Wiki 页面并展示面板。全站下载开始前需要用户在 Chrome 手动加载扩展；助手并未替用户安装或授予浏览器权限。
