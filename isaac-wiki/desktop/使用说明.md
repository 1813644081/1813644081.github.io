# Windows 可执行下载器

双击上一级目录的 `IsaacWikiDownloader.exe`。保留整个 `isaac-wiki` 文件夹，不要只复制 EXE；Node 运行时和微软 WebView2 组件已放在配套目录中。

程序使用微软 WebView2 作为内部网页引擎，无需打开 Chrome、Edge 窗口，也无需加载 Chrome 扩展。本机已检测到 WebView2 Runtime。它使用自己的程序配置目录，不读取或复制现有 Chrome 的 Cookie、密码或个人浏览资料。

1. 启动程序后，“原站验证”页会连接 Wiki。如果显示原站要求的验证，由你在程序内正常完成。
2. 点击“开始 / 继续下载”。正常访问公开 API 后，程序自动枚举所有当前公开页面和上传素材，显示页面、素材、待下载和错误数量。
3. 图片或字体域名如果要求验证，下载会暂停并切换到“素材验证”页。完成验证后点击“开始 / 继续下载”。程序不自动完成 CAPTCHA。
4. “暂停”保留已下载文件和进度；“重试失败任务”重新排队失败项目，然后点击开始。
5. “浏览本地 Wiki”在程序内部打开离线阅读页。全站下载完成后可完全断网使用。

下载期间保持程序运行，可以最小化窗口。若关闭程序，会保存已完成任务并暂停；下次继续。由本程序启动的本地服务会随程序退出；如果服务此前已由其他方式运行，程序不会关闭它。

速度菜单默认“加速：2 路 / 200 ms”。开始前可以选择“稳妥：1 路 / 350 ms”或“更快：4 路 / 150 ms”；每路在完成一项后等待所选间隔。页面和目录可并发，素材仍在页面结束后单路处理。暂停后等待当前任务停止即可切换速度。遇到 429 限流会暂停并显示建议等待时间，随后可改用稳妥模式继续。进度中的“本轮平均”包含原站请求、处理和等待时间，不等同于网络带宽。

保存范围和静态功能限制与主目录 README 一致。只有枚举结束、队列为空、失败和遗漏均为零才显示完整成功。验证失败、限流或其他网络错误会明确显示，不能保证原站永远允许批量下载。

开发组件来自 Microsoft.Web.WebView2 官方 NuGet 包 1.0.4258.31，微软组件许可证保存在本目录。Node 运行时来自本机已有官方安装，不要求另外安装 Node。应用源码为 `Downloader.cs`、`worker.js`；构建脚本为 `build.ps1`。
