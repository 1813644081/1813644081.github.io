# png-cloak 🔍

把一张图片(或任意文件)**原样藏进**另一张 PNG 里,也可以随时**解出来**。

自带两种引擎:
1. **容器隐写**(`hide` / `extract`):在 PNG 末尾加自定义数据块——**像素一个字节都不动**;
2. **LSB 像素隐写**(`hide-lsb` / `extract-lsb`):数据写进像素低位,肉眼无痕,
   必须用 PNG 无损保存(思路参考 [WarFactory 的无影坦克](https://github.com/fEndman/WarFactory),格式独立)。

- **CLI 版**:`cli.mjs`,零依赖,需要 Node.js 18+
- **网页版**:`web.html`,双击用浏览器打开即可(纯本地处理,不上传)
- 核心逻辑:`core.mjs`(PNG 分块)+ `lsb.mjs`(像素解码 / LSB 读写)

## 原理(30 秒版)

PNG 文件 = `8字节签名 + 一串 chunk`,每个 chunk 是:

```
[4字节长度][4字节类型名][数据][4字节 CRC32]
```

**引擎 A(容器)**:把秘密文件的原始字节做成一个**自定义 chunk**(默认块名 `hide`,
全小写代表 PNG 规范里的"可选 / 私有 / 可安全忽略"块),插到 `IEND` 结束块之前。
不认识该块的图片解码器会按规范**安全忽略**它,所以载体图照样打开、原有内容
(tEXt 角色卡 JSON、像素)一个字节都不动。

**引擎 B(LSB)**:参考"无影坦克"——秘密文件(带长度/文件名头)按"高位在前"
逐位写进每个像素 RGB 的低 `b` 位(`b`=1..7,越大容量越大、痕迹越明显);
容量 = `宽×高×3×b/8` 字节;肉眼看不出变化,但**转成 JPEG 或有损重编码会丢**。

⚠️ 两种都不是加密,只是隐藏——知道方法的人都能解出来。

## CLI 用法

```bash
# ── 引擎 A:容器隐写(不动像素,可藏任意文件) ───────────────
node cli.mjs hide       载体.png 秘密图.jpg -o 藏好.png    # 隐藏
node cli.mjs extract    藏好.png -o 拿回来.jpg             # 提取
node cli.mjs list       藏好.png                          # 查看块

# ── 引擎 B:LSB 像素隐写(肉眼无痕,须 PNG 无损保存) ───────
node cli.mjs hide-lsb    载体.png 秘密图.jpg -o 藏好.png   # 默认 3 位/通道
node cli.mjs hide-lsb    载体.png 秘密图.jpg -b 1 -o 藏好.png  # 1 位最隐蔽
node cli.mjs extract-lsb 藏好.png -o 拿回来.jpg            # -b 省略则自动探测
node cli.mjs probe       藏好.png                         # 像素信息 + 是否有 LSB
```

实际跑一遍(引擎 A 的效果见上;这里演示引擎 B):

```
$ node cli.mjs hide-lsb 角色卡.png 私图.png -o 角色卡LSB.png
✓ 已 LSB 隐写: 52.0 KB 的 PNG 图片(3 位/通道)
  图片 512x768,容量 432.0 KB → 文件 775.7 KB → 819.6 KB
  输出: 角色卡LSB.png
  角色卡等 tEXt 文本块已保留。
结构自检:
  ✓ 所有块 CRC32 校验通过
  ✓ 像素流可解压: 512x768 colorType=6 ...(吻合)
  回读比对: ✓ 提取结果与原文完全一致

$ node cli.mjs extract-lsb 角色卡LSB.png -o 拿回来.png
✓ 提取出 52.0 KB 的 PNG 图片(LSB 3 位/通道,原文件名: 私图.png)
```

> 载体不要求是"空白图",任意 PNG 都行——角色卡、截图、头像都可以。
> 两种引擎可以组合:**先做 LSB(改像素),再做容器(加块)**,互不干扰。

## 网页版用法

双击打开 `web.html`,四个面板:

- **① 隐藏(容器)**:选载体 PNG → 选要藏的文件 → 「隐藏并下载」;
- **② 提取(容器)**:选 PNG → 「提取」(块名留空会自动识别);
- **③ LSB 隐藏**:选载体 PNG → 选要藏的文件 → 填位数(1-7)→ 「LSB 隐藏」;
- **④ LSB 提取**:选 PNG → 「LSB 提取」(位数留空自动探测)。

产物都会先预览再触发下载;全程在浏览器本地完成。
注意:网页版走 `<canvas>` 解码/重编码,与 CLI 的格式互通(本工具生成的图互提没问题);
但浏览器可能对带色彩配置的 PNG 做校色,以及重编码会丢 tEXt 角色卡块——
**角色卡请优先用 CLI**,网页版适合普通图片。

## 注意事项

1. **两种引擎对 SillyTavern 的兼容性不同**:
   - 容器隐写:角色卡放进 ST 编辑器保存一次(Jimp 重编码)会把自定义块抹掉,
     只读不改则没事;
   - LSB 隐写:藏在像素里,ST 编辑头像时若走 Jimp 重编码**同样会丢**;
   - 想"跟着角色走且不怕编辑",应把图片 base64 写进角色卡 JSON 的
     `data.extensions` 字段(那条路 ST 会原样保留)。
2. LSB 隐写**怕有损压缩**:转成 JPEG、被聊天软件/图床重编码就丢,请全程 PNG。
3. 不建议用"IEND 之后拼尾数据"的同类做法:不遵守规范,很多严格解码器会截断。
4. 隐藏内容是明文,不要用来存密码/密钥。
